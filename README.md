# 🏓 Ping Pong 2D
 
Простая 2D-игра Ping Pong, написанная на Python с использованием библиотеки Pygame.
 
## 🎮 Описание
 
В игре два игрока управляют ракетками и пытаются отбить мяч на сторону соперника.
 
Цель игры — набрать больше очков, чем противник.
 
## 🛠️ Используемые технологии
 
- 🐍 Python 3
- 🎮 Pygame
## 📦 Установка
 
### Клонирование репозитория
 
```bash
git clone https://github.com/USERNAME/ping_pong.git
cd ping_pong
```
 
### Установка зависимостей
 
Установите необходимые библиотеки:
 
```bash
pip install -r requirements.txt
```
 
Или установите Pygame вручную:
 
```bash
pip install pygame
```
 
## ▶️ Запуск игры
 
Запустите основной файл:
 
```bash
python main.py
```
 
## 🎮 Управление
 
| Игрок | Движение вверх | Движение вниз |
|---|---|---|
| 🟦 Игрок 1 | W | S |
| 🟥 Игрок 2 | ↑ | ↓ |
 
### Дополнительные клавиши
 
| Клавиша | Действие |
|---|---|
| ESC | Выход из игры |
| R | Перезапуск игры |

- Движение двух ракеток
